## 设计系统 v2（深色全站背景，详见《视觉设置与叙事说明.md》）

- **背景**：`hardcore-starship.jpeg` 星舰图作为**全站背景**（fixed cover + `saturate(0.78)` + 通透三段蒙层 0.55/0.30/0.72），图片实测 71.8% 暗区，深蓝青调；背景路径相对 CSS 为 `images/bg-starship.jpg`
- **色彩（反转）**：深墨底 `#0E1418` / 雾白字 `#EAF0F2` / 亮钢青 `#8FA9BB` / 琥珀金 `#D4A84F`（仅证据数字与结论行）
- **玻璃拟态**：卡片/观点/引用/联系卡均为半透明深墨 + `backdrop-blur`，背景图透出但正文可读
- **字体**：思源宋体（标题）、思源黑体（正文）、IBM Plex Mono（数字/标签）
- **动效**：滚动淡入 + 数字计数，尊重 `prefers-reduced-motion`
- **叙事**：星舰 = 驶向未知现场 / 硬核工程 / 真实结果；首页 hero 底部签名行「HARD-CORE STARSHIP // FIELD FIRST · 现场/真实/验收」
